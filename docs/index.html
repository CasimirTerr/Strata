      Why I built this

      Most published Bedrock detections only watch for logging being deleted. The research shows attackers have quieter options, like redirecting the logs or swapping the Lambda behind an agent's tool, and those weren't covered.

      Turn on data events

      The memory, code interpreter and image-pull checks need CloudTrail data events for bedrock-agentcore and ECR. Management events alone cover everything else.

      Same engine, everywhere

      This page runs the same rules as the Python command line tool, which also runs in CI or as an hourly Lambda that alerts through SNS. Both are tested against each other on hundreds of log sets.
